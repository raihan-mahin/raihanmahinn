# Mahin OS


An interactive personal portfolio by **Raihan Mahin**. A desktop-inspired interface brings my marketing experience, creative projects and business case competitions into one place, with a separate phone-friendly experience.


**[Explore the live website](https://raihanmahinn.lovable.app)**


## Why I built it


I wanted recruiters and collaborators to explore my work through an engaging digital experience. The portfolio connects my background in brand marketing and strategy with my interest in using AI tools to turn ideas into working products.


## Explore the portfolio


- **Files and Photos:** browse experience, creative work, project stories and competition achievements.
- **Notes:** read about my background and work.
- **Messages:** explore a local portfolio Q&A through suggested questions. This does not send real messages.
- **Resume:** review my professional background.
- **Settings:** personalize the appearance, with preferences stored locally.
- **Responsive navigation:** desktop-style windows and a phone-friendly app layout.


## How it was made


I provided the project brief and shaped the content, design and interactions through iterative revisions.


The interface draws inspiration from desktop and mobile operating systems and [Shotok OS](https://shotok.io/), adapted to my own career content.


## Technology


React, TypeScript and TanStack Router. The source code is available in this repository and kept in sync through GitHub.
